## Question 8
Ohms Xerox Duplicate Orders and Messy Product Names. 
First call drop_duplicates() on the raw data and note the row count. Then clean the text (strip spaces, consistent capitalization) in customer and product, and remove duplicates again. Compute total revenue before cleaning and after cleaning. Interpret: by what percentage did bad data inflate the revenue figure, and why did the first attempt miss a duplicate?

## Aim
To clean messy text, remove duplicates properly and see how much bad data inflates revenue

## Code

```
import pandas as pd

orders = pd.DataFrame({
    'order_id': [101, 102, 103, 101, 104, 105, 106, 105],
    'customer': ['Asha', 'ravi', 'Meera', 'Asha', 'Kiran', 'ravi', 'Meera', 'Ravi'],
    'product': ['laptop bag', 'Laptop Bag ', 'desk lamp', 'laptop bag', 'DESK LAMP', 'notebook', 'Notebook', 'Notebook '],
    'amount': [1200, 1200, 900, 1200, 900, 150, 150, 150]})
print(len(orders), len(orders.drop_duplicates()))
raw_rev = orders['amount'].sum()
print(raw_rev)

orders['customer'] = orders['customer'].str.strip().str.title()
orders['product'] = orders['product'].str.strip().str.title()
clean = orders.drop_duplicates()
print(clean)
print(len(clean), clean['product'].nunique())
clean_rev = clean['amount'].sum()
print(clean_rev)
print((raw_rev - clean_rev) / clean_rev * 100)
```

## Explanation
raw drop_duplicates only removes exact copies so rows go 8 to 7 
the second order 105 row was missed because 'ravi' and 'Ravi' and 'Notebook' and 'Notebook ' differ in case and trailing space  
str.strip() removes the spaces and str.title() makes the capitalization the same  
after cleaning 6 rows are left with 3 distinct products  
revenue is 5850 raw and 4500 cleaned  
bad data inflated revenue by 30%
