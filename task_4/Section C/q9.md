## Question 9
Player Efficiency. Using a vectorized operation, add score_per_min. 
Using a vectorized operation, add score_per_min. Using apply with a small function, add a tier column: Elite for scores of 6000 or more, Skilled for 3000 to 5999, Rookie otherwise. Using map, convert the tier into bonus points (Elite 500, Skilled 200, Rookie 50) and compute the total bonus. Interpret: is the top scorer also the most efficient player?

## Aim
To create new columns using vectorized operations, apply and map.

## Code

```
import pandas as pd

players = pd.DataFrame({'player': ['A', 'B', 'C', 'D', 'E', 'F'],
                        'score': [4200, 1800, 7600, 3100, 5900, 900],
                        'minutes': [30, 45, 60, 20, 40, 15]})
players['score_per_min'] = players['score'] / players['minutes']

def tier(s):
    if s >= 6000:
        return 'Elite'
    elif s >= 3000:
        return 'Skilled'
    return 'Rookie'

players['tier'] = players['score'].apply(tier)
players['bonus'] = players['tier'].map({'Elite': 500, 'Skilled': 200, 'Rookie': 50})
print(players)
print(players['bonus'].sum())
print(players.loc[players['score'].idxmax(), 'player'], players.loc[players['score_per_min'].idxmax(), 'player'])
```

## Explanation
score / minutes works on the whole column at once so no loop is needed 
apply(tier) runs the small function on every score  
map uses the dictionary to turn each tier into bonus points  
C is Elite, A, D, E are Skilled, B and F are Rookie, total bonus is 1200  
top scorer is C but D has the best score_per_min 
so the top scorer is not the most efficient player
