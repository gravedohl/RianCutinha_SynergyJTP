## Question 7
The Faulty Manipal Weather Station. 
Count missing values per column and the number of rows with at least one missing value. Drop rows where both readings are missing. Then fill the remaining missing temp_c and humidity values with the median of each column. Day 6 (55.0 °C) is almost certainly a sensor fault. Interpret: compare the temperature mean and median. Why is the median the safer fill value here?

## Aim
To find and handle missing values and see why the median is safer than the mean when there is an outlier

## Code

```
import numpy as np
import pandas as pd

weather = pd.DataFrame({'day': range(1, 11),
                        'temp_c': [28.1, 29.0, np.nan, 30.2, 29.5, 55.0, np.nan, 27.8, 28.6, 29.3],
                        'humidity': [64, 61, 63, np.nan, 60, 58, np.nan, 66, 65, 62]})
print(weather.isna().sum())
print(weather.isna().any(axis=1).sum())

weather = weather.dropna(subset=['temp_c', 'humidity'], how='all')
print(len(weather))

print(weather['temp_c'].mean(), weather['temp_c'].median())
weather['temp_c'] = weather['temp_c'].fillna(weather['temp_c'].median())
weather['humidity'] = weather['humidity'].fillna(weather['humidity'].median())
print(weather)
```

## Explanation
isna().sum() gives 2 missing in temp_c and 2 in humidity  
isna().any(axis=1).sum() counts rows with at least one missing value, which is 3  
dropna(how='all') only drops a row if both readings are missing 
the remaining NaNs are filled with each columns median  
temp mean is 32.19 but median is 29.15, the faulty 55.0 pulls the mean up a lot so median is the safer fill as it is not affected by the sensor fault but the mean would fill in fake high temperatures
