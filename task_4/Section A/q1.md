## Question 1
Fest Attendance Check
Build a DataFrame and print its shape and dtypes. Add an attendance_rate column (attended ÷ registered × 100, rounded to 1 decimal). Find the event with the most registrations and the event with the highest attendance rate. Interpret: are they the same event, and what does that say about judging an event by registrations alone?

## Aim
To build a DataFrame of event data
To add an attendance rate column and,
To compare the most registered event with the best attended one.

## Code

```
import pandas as pd

events = {'event': ['City Scaping', 'salutes and ladders', 'Open Mic', '', 'Valorant tournament'],'registered': [180, 95, 140, 60, 210],'attended': [150, 70, 135, 52, 160],'fee': [200, 150, 0, 50, 100]}
df = pd.DataFrame(events)
print(df.shape)
print(df.dtypes)

df['attendance_rate'] = (df['attended'] / df['registered'] * 100).round(1)
print(df)

print(df.loc[df['registered'].idxmax(), 'event'], df['registered'].max())
print(df.loc[df['attendance_rate'].idxmax(), 'event'], df['attendance_rate'].max())
```

## Explanation

dtypes shows event as str and the rest as int64  
round(1) rounds it to 1 point

valorant tournament has the most registrations but its rate is only 76.2  
open mic has the best rate so they are not the same event  
so judging an event by registrations alone is misleading lots of people register but dont show up
