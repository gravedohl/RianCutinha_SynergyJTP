## Question 24
Telling the Revenue Story. 
Use pct_change to compute month-over-month growth. Plot revenue as a line with markers, write the value above each point, and use annotations with arrows to mark the month with the highest growth and the month with the biggest drop. Set a suitable figure size, axis labels and a title that states the finding. Interpret: write one sentence the founder could present to investors.

## Aim
To calculate month over month growth and plot revenue with value labels and arrow annotations

## Code

```
import pandas as pd
import matplotlib.pyplot as plt

revenue = pd.DataFrame({'month': ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
                        'revenue': [12, 15, 21, 19, 24, 22]})
revenue['growth'] = (revenue['revenue'].pct_change() * 100).round(1)
print(revenue)

best = revenue['growth'].idxmax()
worst = revenue['growth'].idxmin()
print(revenue['month'][best], revenue['growth'][best])
print(revenue['month'][worst], revenue['growth'][worst])

plt.figure(figsize=(9, 5))
plt.plot(revenue['month'], revenue['revenue'], marker='o')

for i in range(len(revenue)):
    plt.text(i, revenue['revenue'][i] + 0.6, revenue['revenue'][i], ha='center')

plt.annotate('Highest growth (+40.0%)', xy=(best, revenue['revenue'][best]),
             xytext=(0.3, 22), arrowprops=dict(arrowstyle='->'))
plt.annotate('Biggest drop (-9.5%)', xy=(worst, revenue['revenue'][worst]),
             xytext=(3, 14), arrowprops=dict(arrowstyle='->'))

plt.xlabel('Month')
plt.ylabel('Revenue (₹ lakh)')
plt.title('Revenue Nearly Doubled in Six Months, Led by a 40% Jump in March')
plt.show()
```

## Explanation
pct_change() gives the change from the previous month, Jan is NaN because there is no month before it  
idxmax and idxmin on growth give the row number of the best month: mar, +40.0% and the worst month: apr, -9.5%  
the for loop uses plt.text to write each revenue value just above its point  
annotate puts a text label with an arrow pointing at the point xy, xytext is where the text sits  
the title states the finding so the chart explains itself  
one sentence for investors would be revenue grew from 12 to 22 lakh in six months, with the strongest month in march and only small dips in april and june
