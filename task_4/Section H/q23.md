## Question 23
Goal Check Across Two Weeks.
Create a figure with two subplots side by side that share the y-axis, one per week. Draw bars for the daily steps, add a horizontal reference line at the 8000-step goal, color bars below the goal differently, and give each subplot a title. Use one overall figure title and a sensible figure size. Interpret: did the user improve in the second week?

## Aim
To compare the daily steps of two weeks against an 8000 step goal using two bar charts side by side

## Code

```
import matplotlib.pyplot as plt

week1 = [8200, 10400, 6100, 12000, 9800, 3000, 7500]
week2 = [9000, 11000, 8500, 7000, 12500, 5000, 9500]
days = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun']
goal = 8000

colors1 = ['green' if s >= goal else 'orange' for s in week1]
colors2 = ['green' if s >= goal else 'orange' for s in week2]

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4), sharey=True)

ax1.bar(days, week1, color=colors1)
ax1.axhline(goal, color='red', linestyle='--')
ax1.set_title('Week 1')
ax1.set_ylabel('Steps')

ax2.bar(days, week2, color=colors2)
ax2.axhline(goal, color='red', linestyle='--')
ax2.set_title('Week 2')

fig.suptitle('Daily Steps vs 8000 Step Goal')
plt.show()

print(colors1.count('green'), colors2.count('green'))
print(sum(week1) / len(week1))
print(sum(week2) / len(week2))
```

## Output

```
4 5
8142.857142857143
8928.57142857143

```

## Explanation
plt.subplots(1, 2, sharey=True) gives 2 plots side by side with the same y-axis, ax1 is week 1 and ax2 is week 2  
colors1 and colors2 give green if the day is 8000 or more and orange if below  
ax.bar draws the bars and axhline draws the red dashed goal line at 8000  
set_title gives each subplot its title and suptitle gives one title for the whole figure  
count('green') counts the days that met the goal 
mean is sum / len 
so yes the user improved in week 2, more days met the goal and the average went up
