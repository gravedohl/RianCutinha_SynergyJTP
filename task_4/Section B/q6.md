## Question 6
Online Store Catalog Search. 
The store manager asks four questions. Answer each with one filter: (a) products whose name contains Pro; (b) products in the Stationery or Home categories (isin); (c) products priced between 300 and 1500 inclusive (between); (d) Pro products that sold fewer than 70 units. Interpret: what does (d) suggest about premium products in this store?

## Aim
To filter a product catalog using str.contains, isin, between and multiple conditions.

## Code

```
import pandas as pd

catalog = {'product': ['USB-C Hub Pro', 'Notebook A5', 'Gel Pen Pack', 'Laptop Stand Pro',
                       'Desk Lamp', 'Mouse Pad XL', 'Webcam Pro', 'Sticky Notes'],
           'category': ['Electronics', 'Stationery', 'Stationery', 'Electronics',
                        'Home', 'Accessories', 'Electronics', 'Stationery'],
           'price': [1299, 120, 90, 1599, 899, 349, 2499, 60],
           'units_sold': [85, 400, 520, 60, 110, 230, 25, 610]}
df = pd.DataFrame(catalog)
a = df[df['product'].str.contains('Pro')]
b = df[df['category'].isin(['Stationery', 'Home'])]
c = df[df['price'].between(300, 1500)]
d = df[df['product'].str.contains('Pro') & (df['units_sold'] < 70)]
print(a, len(a), sep='\n')
print(b, len(b), sep='\n')
print(c, len(c), sep='\n')
print(d, len(d), sep='\n')
```

## Explanation
(a) str.contains('Pro') checks the product name gives 3 products  
(b) isin takes a list of categories, gives 4 products  
(c) between(300, 1500) includes both ends, gives 3 products  
(d) combines the Pro filter and units_sold < 70 with &, gives 2 products 
so the more expensive pro products sell very few units, most sales come from cheap stationery items
