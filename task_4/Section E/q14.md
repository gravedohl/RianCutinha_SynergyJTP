## Question 14
Delhi's Traffic and Air Quality. 
Combine them with concat (reset the index) and add a week column. Compute the correlation between vehicles and PM2.5 and the mean PM2.5 for each week. Interpret: if the city declares an alert when the weekly mean exceeds 70, which week triggers it? Name one other factor besides traffic that could also influence PM2.5.

## Aim
To combine two weekly logs with concat and check the relationship between traffic and PM2.5

## Code

```
import pandas as pd

week1 = pd.DataFrame({'vehicles_k': [30, 35, 40, 45], 'pm25': [52, 55, 60, 63]})
week2 = pd.DataFrame({'vehicles_k': [50, 55, 60, 65], 'pm25': [68, 72, 75, 80]})
week1['week'] = 1
week2['week'] = 2
both = pd.concat([week1, week2], ignore_index=True)
print(both.shape)
print(both['vehicles_k'].corr(both['pm25']))
print(both.groupby('week')['pm25'].mean())
```

## Output

```
(8, 3)
0.9986204405383659
week
1    57.50
2    73.75
Name: pm25, dtype: float64

```

## Explanation
the week column is added to each table before concat so we know which row came from which week  
ignore_index=True resets the index to 0 to 7, shape is (8, 2) before the week column so (8, 3) after  
correlation is about 0.999 
weekly means are 57.5 and 73.75  
week 2 crosses 70 so it triggers the alert  
another factor can be weather, like wind speed or low temperature or industries
