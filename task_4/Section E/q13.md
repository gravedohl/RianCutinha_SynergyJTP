## Question 13
The Catalog Gap. 
Merge the tables with an inner, a left and an outer join, and record the row count of each. The platform wants a report listing every catalog track, including tracks never played. Choose the correct join, fill missing plays with 0, and compute total plays per artist. Interpret: what does the unmatched track_id 5 tell you about the data, and which join type hides it?

## Aim
To compare inner, left and outer joins and make a report keeping every catalog track

## Code

```
import pandas as pd

tracks = pd.DataFrame({'track_id': [1, 2, 3, 4],
                       'title': ['Neon Drive', 'Gravity', 'Night Bus', 'Dust Roads'],
                       'artist': ['Aria', 'Vega', 'Aria', 'Mohan']})
plays = pd.DataFrame({'track_id': [1, 2, 3, 5], 'plays': [520, 450, 280, 90]})

inner = pd.merge(tracks, plays, on='track_id', how='inner')
left = pd.merge(tracks, plays, on='track_id', how='left')
outer = pd.merge(tracks, plays, on='track_id', how='outer')
print(len(inner), len(left), len(outer))

left['plays'] = left['plays'].fillna(0)
print(left)
print(left.groupby('artist')['plays'].sum())
```

## Explanation
inner keeps only the matching track_ids so 3 rows  
left keeps all the tracks from the first table so 4 rows  
outer keeps everything from both tables so 5 rows  
the report needs every catalog track so left join is the correct one  
fillna(0) puts 0 for Dust Roads since it was never played  
track_id 5 has plays but is not in the catalog so something is wrong with the data  
inner and left joins both hide it, only outer shows it
