## Question 17
Why Are Sales Falling? 
Values are monthly sales in ₹ lakh. Use Pandas to add a total column, then plot phones, accessories and total as three lines (make the total dashed). Add markers, a legend and a title. Interpret: the owner says everything is declining. Is that true? Identify which category drives the fall in total sales and which one is growing.

## Aim
To plot sales of each category with the total and find which category drives the fall

## Code

```
import pandas as pd
import matplotlib.pyplot as plt

store = pd.DataFrame({'month': ['Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep'],
                      'phones': [120, 125, 118, 110, 95, 80],
                      'accessories': [60, 62, 65, 66, 70, 75]})
store['total'] = store['phones'] + store['accessories']
print(store)

plt.plot(store['month'], store['phones'], marker='o', label='Phones')
plt.plot(store['month'], store['accessories'], marker='s', label='Accessories')
plt.plot(store['month'], store['total'], marker='^', linestyle='--', label='Total')
plt.xlabel('Month')
plt.ylabel('Sales ')
plt.title('Monthly Sales by Category')
plt.legend()
plt.show()

print(store['total'].idxmax(), store['total'].max())
print(store['total'].iloc[-1] - store['total'].iloc[0])
print(store['phones'].iloc[-1] - store['phones'].iloc[0])
print(store['accessories'].iloc[-1] - store['accessories'].iloc[0])
```
