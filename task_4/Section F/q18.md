## Question 18
Who Is Buying the Tickets? 
Draw a stacked bar chart of tickets sold per day, split by internal and external visitors. Then draw a grouped bar chart of the same data in a second figure. Design: which chart better shows the total footfall, and which better compares internal against external visitors? Justify in two sentences. Compute the external share for each day and state when the fest was most dependent on outside visitors.

## Aim
To draw stacked and grouped bar charts of tickets sold and compute the external visitor share

## Code

```
import numpy as np
import matplotlib.pyplot as plt

day = ['Day 1', 'Day 2', 'Day 3']
internal = np.array([120, 150, 90])
external = np.array([30, 80, 160])

plt.bar(day, internal, label='Internal')
plt.bar(day, external, bottom=internal, label='External')
plt.xlabel('Day')
plt.ylabel('Tickets sold')
plt.title('Tickets Sold per Day (Stacked)')
plt.legend()
plt.show()

x = np.arange(len(day))
plt.bar(x - 0.2, internal, width=0.4, label='Internal')
plt.bar(x + 0.2, external, width=0.4, label='External')
plt.xticks(x, day)
plt.xlabel('Day')
plt.ylabel('Tickets sold')
plt.title('Tickets Sold per Day (Grouped)')
plt.legend()
plt.show()

total = internal + external
print(total)
print((external / total * 100).round(1))
```

## Output

```
[150 230 250]
[20.  34.8 64. ]

```

## Explanation
stacked bars use bottom=internal so the external bars sit on top of the internal ones  
grouped bars are placed side by side by shifting the x positions by -0.2 and +0.2  
the stacked chart shows total footfall better because the full bar height is the total  
the grouped chart compares internal against external better because both bars start from zero next to each other  
daily totals are 150, 230, 250 and external share is 20.0%, 34.8%, 64.0%  
Day 3 is when the fest depended most on outside visitors
