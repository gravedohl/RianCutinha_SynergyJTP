## Question 19
Does Practice Really Drive Skill? 
Plot a scatter chart of hours against rating and highlight the player with 20 hours in a different color. Use Pandas to compute the correlation twice: once with all ten players and once without the 20-hour player. Interpret: does the data support the coach’s claim for typical players?

## Aim
To see how a single outlier can create a strong correlation using a scatter plot and corr()

## Code

```
import pandas as pd
import matplotlib.pyplot as plt

players = pd.DataFrame({'hours': [1, 2, 3, 4, 5, 6, 7, 8, 9, 20],
                        'rating': [50, 56, 48, 55, 52, 57, 49, 54, 51, 95]})
top = players[players['hours'] == 20]
rest = players[players['hours'] != 20]

plt.scatter(rest['hours'], rest['rating'], color='blue', label='Other players')
plt.scatter(top['hours'], top['rating'], color='red', label='20 hour player')
plt.xlabel('Practice hours per week')
plt.ylabel('Skill rating')
plt.title('Practice Hours vs Skill Rating')
plt.legend()
plt.show()

print(players['hours'].corr(players['rating']))
print(rest['hours'].corr(rest['rating']))
```

## Output

```
0.8599438484105459
0.02847473987257497

```

## Explanation
the 20 hour player is split out and plotted in red so it stands out from the rest  
correlation with all ten players is about 0.86 which looks like a strong relationship  
without the 20 hour player it drops to about 0.03 which is basically no relationship  
the other nine players stay around 48 to 57 rating no matter how many hours they practice  
so the data does not support the coach's claim for typical players, one outlier is creating the correlation
