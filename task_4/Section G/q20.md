## Question 20
Traffic Is Not the Whole Story. 
Plot vehicles (x-axis) against PM2.5 (y-axis). Use a dictionary and map to color points by zone, scale marker size by population, and add a legend that names the zones. Interpret: which stations break the “more traffic means more pollution” pattern, and what variable explains them?

## Aim
To plot traffic against PM2.5 with colors by zone and marker size by population and find the stations that break the pattern

## Code

```
import pandas as pd
import matplotlib.pyplot as plt

stations = pd.DataFrame({
    'station': ['S1', 'S2', 'S3', 'S4', 'S5', 'S6', 'S7', 'S8'],
    'vehicles_k': [35, 40, 65, 60, 45, 50, 70, 30],
    'pm25': [58, 60, 80, 77, 110, 115, 83, 52],
    'zone': ['Residential', 'Residential', 'Commercial', 'Commercial',
             'Industrial', 'Industrial', 'Commercial', 'Residential'],
    'population_k': [40, 45, 30, 25, 15, 10, 35, 50]})
colors = {'Residential': 'green', 'Commercial': 'blue', 'Industrial': 'red'}

plt.scatter(stations['vehicles_k'], stations['pm25'],c=stations['zone'].map(colors), s=stations['population_k'] * 8, alpha=0.7)
for z, c in colors.items():
    plt.scatter([], [], color=c, label=z)
plt.xlabel('Vehicles (thousands)')
plt.ylabel('PM2.5 (µg/m³)')
plt.title('Vehicles vs PM2.5 by Zone')
plt.legend(title='Zone')
plt.show()

print(stations[stations['pm25'] > 100])
print(stations.loc[stations['vehicles_k'].idxmax()])
```

## Explanation
the dictionary colors maps each zone to a color and map() applies it to the whole zone column  
s=population_k * 8 makes the marker size grow with population  
the legend is made with empty scatter calls so each zone name gets its own entry, otherwise the legend would not name the zones  
S5 and S6 are both Industrial and have PM2.5 above 100 at only 45 to 50k vehicles  
S7 is the busiest station but only has 83  
so the zone industrial activity explains them, not traffic
