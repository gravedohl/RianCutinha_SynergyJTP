## Question 22
Which Level Is Unfair? 
These are completion times in minutes. Draw side-by-side box plots for the three levels. Then use Pandas to compute the median and IQR of each level and apply the 1.5 × IQR rule to list any outliers. Interpret: which level has an unusual completion time, and should the designers worry about the level or about one player?

## Aim
To draw box plots of completion times and detect outliers using the 1.5 × IQR rule

## Code

```
import pandas as pd
import matplotlib.pyplot as plt

times = pd.DataFrame({
    'Level 1': [5, 6, 6, 7, 7, 8, 8, 9],
    'Level 2': [10, 11, 12, 12, 13, 14, 15, 40],
    'Level 3': [15, 16, 18, 18, 19, 20, 22, 24]})

plt.boxplot([times[c] for c in times.columns])
plt.xticks([1, 2, 3], times.columns)
plt.xlabel('Level')
plt.ylabel('Completion time (minutes)')
plt.title('Completion Time by Level')
plt.show()

q1 = times.quantile(0.25)
q3 = times.quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
print(times.median())
print(iqr)
print(upper)
for c in times.columns:
    print(c, times[c][(times[c] < lower[c]) | (times[c] > upper[c])].tolist())
```

## Explanation
boxplot is given a list of the three columns so they are drawn side by side and xticks puts the level names  
medians are 7, 12.5 and 18.5  
IQR = Q3 - Q1 and anything above Q3 + 1.5 * IQR or below Q1 - 1.5 * IQR is an outlier  
Level 2 has IQR 2.5 and upper fence 18.0 so the 40 is above it  
the only outlier in the whole data is the 40 in Level 2  
the other Level 2 times are 10 to 15 which is normal so the designers should worry about that one player and not the level
