## Question 12
The Misleading Conversion Rate. 
Run the code and note the result. Explain what is wrong with averaging the daily rates when the visitor counts differ so much. Fix the analysis by aggregating the right columns first and computing the rate afterwards. Decision: which channel should the jio invest in?

## Aim
To see why averaging rates is misleading when sample sizes differ and to fix it by aggregating first.

## Code

```
import pandas as pd

funnel = pd.DataFrame({'channel': ['A', 'A', 'B', 'B'],
                       'visitors': [10, 490, 100, 100],
                       'signups': [6, 49, 20, 20]})
funnel['rate'] = funnel['signups'] / funnel['visitors'] * 100
print(funnel.groupby('channel')['rate'].mean())

fixed = funnel.groupby('channel')[['visitors', 'signups']].sum()
fixed['rate'] = fixed['signups'] / fixed['visitors'] * 100
print(fixed)
```

## Output

```

         visitors  signups  rate

A             500       55  11.0
B             200       40  20.0

```

## Explanation
the teammates code gives A = 35.0 and B = 20.0 so it looks like A wins  
the problem is the mean of rates treats a day with 10 visitors the same as a day with 490 visitors  
A's tiny day has a 60% rate which pulls the average way up  
the fix is to sum visitors and signups first and then divide
so channel B is the better one and jio should invest in B
