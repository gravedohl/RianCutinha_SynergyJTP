## Question 11
Highest Revenue, Highest Profit? 
Create revenue and profit columns per row, then group by product and sum both. Sort to find the leader for each measure and compute each product’s profit margin (total profit ÷ total revenue × 100). Decision: which product deserves the promotion budget, and which one looks successful only because of its price?

## Aim
To compare revenue, profit and margin per product using groupby and sum.

## Code

```
import pandas as pd

sales = pd.DataFrame({
    'product': ['Phone Case', 'Phone Case', 'Earbuds', 'Earbuds', 'Smart Watch', 'Smart Watch',
                'Power Bank', 'Power Bank', 'Screen Guard', 'Screen Guard'],
    'month': ['Aug', 'Sep'] * 5,
    'units': [180, 120, 100, 50, 50, 40, 90, 110, 300, 200],
    'price': [299, 299, 1499, 1499, 2999, 2999, 999, 999, 99, 99],
    'cost': [120, 120, 1300, 1300, 2700, 2700, 650, 650, 40, 40]})
sales['revenue'] = sales['units'] * sales['price']
sales['profit'] = sales['units'] * (sales['price'] - sales['cost'])
g = sales.groupby('product')[['revenue', 'profit']].sum()
g['margin_pct'] = (g['profit'] / g['revenue'] * 100).round(1)
print(g.sort_values('revenue', ascending=False))
print(g.sort_values('profit', ascending=False))
```
